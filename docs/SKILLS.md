# Prepal AI - Tech Skills & Competencies Reference

This document highlights the list of technologies, patterns, and methodologies utilized across Prepal AI.

---

## 1. Full-Stack Web Development

### React & Frontend Logic
* **Skills:** Functional Components, React Hooks (`useState`, `useEffect`, `useParams`, `useNavigate`), state synchronization, component lifecycles, and Axios request/response interceptors.
* **Layouts:** Responsive mobile-first CSS grids, flexbox panels, responsive sidebars, customized scrollbars, and fluid CSS transitions.

### Django & Python Backend
* **Skills:** Django MVC architecture, RESTful API design using Django REST Framework (DRF) serializers, Django ORM database queries, and URL routing tables.
* **Storage:** Django FileField/ImageField handling, custom migrations, and SQLite DB optimization.

---

## 2. Artificial Intelligence & Prompt Engineering

### Google Gemini API Integration
* **Skills:** Utilizing Python SDKs (`google-genai`), managing secure connections, and handling response schemas.
* **RAG Pipeline:** Context ingestion, hierarchy text retrieval, text concatenation, and prompting styles for educational content.
* **System Prompting:** Context boundary enforcement, zero-shot and few-shot formatting, constraint filters to prevent hallucinations, and structured markdown returns.

---

## 3. DevOps & Quality Assurance

### Environment Management
* **Skills:** Python Virtual Environments (`venv`), Node Package Management (`npm` and `npx`), dependency management via `.venv/bin/pip freeze`, environment file security (`.env` with `python-dotenv`), and binding local servers to standard interfaces (`0.0.0.0`).
* **QA Procedures:** Django Unit Testing, response validation scripts, curl API tests, and browser-driven manual interface checks.
