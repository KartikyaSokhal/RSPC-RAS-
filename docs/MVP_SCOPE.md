# Content-first MVP scope

Preserve React/Vite, Django/DRF, Django Admin and PostgreSQL as normal runtime. SQLite is only the untouched source archive or explicit isolated test/demo backend. The current authorization is documentation cleanup and local verification; no feature implementation, extra deletion, migration, credential/production change, commit, push, merge or deployment.

Enabled: published syllabus/notes, eligible search/files, reviewed stateless quizzes/collections, existing optional Tutor with live mode default-off, and explicit administrative authoring/review/publication. Controlled aliases/tags/relationships, evidence-bound links/popups, related topics and approved tag pages reuse existing models. Source HTML/IDs/slugs and original records remain unchanged; no AI tagging/generation is introduced.

Disabled for every identity: learner registration/login/status/logout, dashboard, bookmarks, progress, saved attempts/reports and study planning. Admin staff authentication is retained. Dormant schema/data is not permission to enable accounts. Practice results remain stateless/browser-only.

The UI uses existing routes/components/themes, original-order tree numbering/expansion, shared honest counts and one bottom-right Tutor launcher. No new search/admin SPA, homepage redesign or unrelated refactoring is included. UI constraints are consolidated in ARCHITECTURE.

Original source hierarchy has five roots/142 topics and is not automatically approved/published. Synthetic methodology fixtures and the academic sample are isolated development data, never an assumed production corpus. Independent academic/rights review remains required.

The sequential master roadmap remains pending beyond the existing local Phase A commit. Cleanup/release review precedes any separately authorized Git operation. Phase C topic-note PDF export/strict current-topic Tutor, approved PostgreSQL source/target/backup/cutover, approved hosting/domain, staging and final production approval remain future gates. No paid AI/service or database migration is authorized by this cleanup. See [roadmap and checklist](IMPLEMENTATION_PLAN.md), [security](SECURITY.md) and [handoff](AGENT_HANDOFF.md).
